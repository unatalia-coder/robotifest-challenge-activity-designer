# Robotifest Challenge & Activity Designer

Aplicación desarrollada mediante Google AI Studio para apoyar el diseño de retos tecnológicos, talleres STEM, actividades educativas y experiencias de divulgación científica alineadas con la metodología Robotifest UCR.

## Objetivo

Facilitar la creación de actividades STEM contextualizadas, considerando variables como:

- Tipo de actividad
- Nivel educativo
- Temáticas STEM
- Modalidad de implementación
- Presupuesto disponible
- Nivel de innovación

## Funcionalidades

- Generación automática de propuestas educativas.
- Modo rápido y modo detallado.
- Selección múltiple de temáticas STEM.
- Inclusión de objetivos de aprendizaje.
- Consideraciones de seguridad e inclusión.
- Recursos y materiales sugeridos.
- Procedimiento paso a paso.
- Exportación de propuestas.

## Tecnologías utilizadas

- Google AI Studio
- Gemini 3.5 Flash
- TypeScript
- HTML
- CSS

## Contexto

Esta aplicación fue desarrollada como parte del caso práctico del curso de Inteligencia Artificial Generativa del Instituto Europeo de Posgrado (IEP).

La herramienta toma como referencia la experiencia del proyecto Robotifest UCR para generar propuestas educativas adaptadas a distintos contextos de aprendizaje STEM.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
